🌉 Chatwoot Evolution Error Bridge

v18.0.1.0.0 Odoo 18 Production Ready

Secure API bridge connecting Chatwoot/Evolution WhatsApp conversations with Odoo's Error Reporter module through n8n automation.

✨ Key Features

🔐 Secure Authentication

Token-based authentication with configurable CORS. Replace insecure public auth with proper security.

📊 Complete Context Tracking

Store all Chatwoot conversation details: conversation_id, contact_id, message_id, full webhook payload.

🚫 Duplicate Prevention

Unique constraint on external reference prevents duplicate error reports from same conversation.

💬 Reply Message Generation

Generate customer-ready WhatsApp messages with error tracking links and status updates.

📱 Phone Sanitization

Automatic cleanup of phone numbers (removes + and @s.whatsapp.net suffixes).

🌐 API Endpoints

POST /bridge/error_reports

Create error report from WhatsApp conversation. Requires X-Bridge-Token header.

POST /bridge/error_reports/<id>/status

Update error status and post note to chatter.

GET /bridge/error_reports/<id>

Retrieve error report details.

GET /bridge/error_reports/<id>/reply_message

Get formatted reply message for sending to customer.

GET /bridge/health

Health check endpoint (no authentication required).

📊 New Fields Added

Extends error.report model with 11 new fields:

  • x_source_platform - whatsapp/chatwoot/web/other
  • x_reporter_phone - Sanitized phone number
  • x_reporter_name - Reporter's name
  • x_reporter_email - Reporter's email
  • x_chatwoot_account_id - Chatwoot account
  • x_chatwoot_inbox_id - Chatwoot inbox
  • x_chatwoot_conversation_id - Critical for replies
  • x_chatwoot_contact_id - Chatwoot contact
  • x_chatwoot_message_id - Last message ID
  • x_chatwoot_payload - Full webhook JSON
  • x_external_ref - Unique reference (CW-xxx)

⚡ Quick Setup

  1. Install module: Apps → Search "Chatwoot Evolution" → Install
  2. Generate token: openssl rand -hex 32
  3. Configure: Settings → General Settings → Chatwoot Bridge
  4. Test: curl https://odoo18.freezonermirror.online/bridge/health
⚠️ Security Notice: Change the default token immediately after installation! Never use the default CHANGE_ME_TO_SECURE_TOKEN in production.

🔗 Integration Flow

WhatsApp → Evolution API → Chatwoot → n8n → Bridge API → Odoo

  1. User sends error message via WhatsApp
  2. Evolution API forwards to Chatwoot
  3. Chatwoot webhook triggers n8n workflow
  4. n8n calls Bridge API with parsed data
  5. Bridge API creates error in Odoo
  6. Confirmation sent back to user via WhatsApp
