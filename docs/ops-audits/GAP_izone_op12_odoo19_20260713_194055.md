## 9) Root causes
### RC1_STATUS_MAP_CLOSED_TO_INBOX
- Finding: openproject.status.map id=12 maps Closed (op_status_id=12) → odoo_stage_id=1 Inbox
- Impact: 35 Closed WPs land in Inbox instead of Done; matches current map (not pull bug)
- Fix direction: D2: change map Closed→Done (stage suitable for project #19) + force pull-only stage refresh even when hash unchanged

### RC2_DONE_STAGE_NOT_ON_PROJECT
- Finding: Project #19 type_rel only includes Inbox(#1) and New(#16); Done stages 6/19 not linked to project #19
- Impact: Mapping to Done may require adding Done stage to project #19 before/while remapping
- Fix direction: D2 prep: ensure a Done stage is available on project #19

### RC3_DESC_V1_CONSERVATIVE
- Finding: _op_description_to_odoo escapes HTML and converts newlines to <br/>; stores also op_description_raw
- Impact: Formatting is flattened markdown→escaped text; may look 'lost formatting' vs OP rich text
- Fix direction: D1: re-pull raw from live OP and overwrite description+op_description_raw; optionally improve renderer later

### RC4_INCREMENTAL_PULL_SKIP
- Finding: Pull filters by updatedAt / hash; unchanged WP skips rewrite even if mapping wrong
- Impact: Fixing Closed→Done alone won't restage old tasks until forced refresh
- Fix direction: D2: one-shot pull-only remapper OR hash-agnostic stage apply for mapped statuses
