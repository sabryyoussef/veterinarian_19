## Item field rules

classifications (item.classification):
bug | enhancement | investigation | support | documentation | deployment | configuration | data_issue | unknown

actions (item.action):
ignore | request_information | update_existing_work | create_work | create_multiple_work_items | escalate | review_only

For every actionable item (action in create_work, create_multiple_work_items, update_existing_work, escalate):
- non-empty title, description
- non-empty current_behavior and expected_behavior
- non-empty acceptance_criteria (list of concrete checks)
- non-empty test_requirements (list)
- source_message_ids must be real message ids from request_json.messages[].id

- questions: targeted questions when facts are missing; empty list only when nothing material is missing

For ignore / review_only:
- acceptance_criteria and test_requirements may be empty
- still cite source_message_ids when relevant

recommended_parent: OpenProject/Dev Hub parent id only if present in candidates/context; else null.
duplicate_candidates: only IDs from work_item_candidates or explicit ids in text.
