# Lead Engine Campaign - Module Documentation

## 1. Module Description
- Technical module name: lead_engine_campaign
- Functional name: Lead Engine Campaign
- Category: Sales/CRM
- Version: 19.0.1.0.0
- Summary: Guided wizard to set up a complete Lead Engine campaign in minutes
- Main dependencies: lead_engine_sequence

Business value:
This module simplifies campaign creation through guided wizards and templates so teams can launch structured lead campaigns quickly with fewer setup errors.

## 2. User Guide
### Prerequisites
1. Install lead_engine_sequence first.
2. Ensure user has rights to campaign wizard and templates.
3. Prepare sequence/playbook assets used by campaigns.

### Basic setup steps
1. Install the module.
2. Open campaign template menus and review defaults.
3. Launch campaign setup wizard.
4. Configure key campaign fields and save.

### Daily usage
1. Create a new campaign from template or wizard.
2. Assign target leads and sequence/playbook.
3. Start campaign and monitor progress.
4. Review outputs and optimize settings.

## 3. Use Case Example
Scenario:
Sales ops needs to launch a new outreach campaign in under 10 minutes.

Example flow:
1. User selects predefined campaign template.
2. Wizard pre-fills campaign structure.
3. User confirms target and timeline.
4. Campaign starts using linked sequence logic.

Expected result:
- Faster campaign launch.
- Consistent campaign structure across team.
- Reduced manual setup mistakes.
